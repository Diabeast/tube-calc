# TubeCalc

Pediatrische Tube Size Calculator — Cole's formule

Een webapp voor het berekenen van de aanbevolen endotracheale tube maat voor kinderen (leeftijd 1–14 jaar).

**Formule:** Tube Size = (Leeftijd / 4) + 4 (uncuffed) of + 3.5 (cuffed)

Oorspronkelijk gemaakt als Xcode/SwiftUI app, omgezet naar webapp voor eenvoudige toegang.

👉 [Live demo](https://diabeast.github.io/tube-calc/)
