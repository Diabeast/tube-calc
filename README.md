# Anesthesie Calculator

TIVA, Kefzol en Tube calculators voor de anesthesie.

- **TIVA Calculator** — Propofol en remifentanil pompstand via spuitpomp
- **Kefzol Calculator Kind** — Cefazoline dosering (30 mg/kg, max 2 gram)
- **Tube Calculator** — Cole's formule voor pediatrische tube maat (0–14 jaar)

👉 [Live demo](https://diabeast.github.io/tube-calc/)
